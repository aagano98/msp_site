# AJG Ventures — site

Public one-page site for AJG Ventures LLC (managed private AI infrastructure), served at
[ajgventures.co](https://ajgventures.co).

Single self-contained `index.html` — no build step, no framework, no external requests
(fonts, scripts, and styles are all inline or system). Deploy is static hosting of this
directory as-is (Vercel: framework preset "Other", no build command, output dir `.`).
