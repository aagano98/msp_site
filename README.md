# Freehold — site

Public one-page site for Freehold (managed private AI infrastructure), a product of
AJG Ventures LLC, served at [freeholdtech.ai](https://freeholdtech.ai).

`ajgventures.co` is the previous domain and 301-redirects here.

Single self-contained `index.html` — no build step, no framework, no external requests
(fonts, scripts, and styles are all inline or system). Deploy is static hosting of this
directory as-is (Cloudflare Pages: no build command, output directory `/`).
